Algorithm 
place(row):
  if row == N: save solution
  for col in 0..N-1:
    if safe(row, col):
      put queen; place(row+1)
      remove queen   // backtrack

Safe check is O(1): one flag each for the column, the diagonal (row+col) and the anti-diagonal (row−col).
